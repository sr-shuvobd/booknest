# 📚 BookNest - Online Book Borrowing Platform

BookNest is a simple web application where users can browse books, view details, and manage their profile. Users can register, login, and update their profile information.

---

## 🚀 Features

- 🔐 User Authentication (Register & Login)
- 📖 Browse All Books
- 🔍 Search Books by Title
- 📂 Filter by Category
- 📘 Book Details Page
- 👤 User Profile & Update Profile
- 📊 Clean UI with Tailwind CSS

---

## 🛠️ Tech Stack

- Next.js (App Router)
- React
- Tailwind CSS
- React Hook Form
- Better Auth
- React Toastify
